1. Інструкції ISA
Опкод	Мнемоніка	Розмір	Прапорці	Що робить
0x04	OUTS addr16	3	-	друкує байти з addr, поки не зустрінеться 0 або не набереться 256 байтів
0x40	CLS	    1	-	обнуляє 256 байтів відеопам'яті
0x41	PLOT	1	C	засвічує піксель x = A, y = B. За межами екрана ставить C і нічого не міняє
0x43	SHOW	1	-	малює відеопам'ять у терміналі

Опкоди 0x4_ - нова група в step. OUTS займає 3 байти, тому його додано в op_size разом з JMP.

2. Формула "байт і біт"
Екран 64x32, по біту на піксель, лежить усередині Memory з адреси 0xA00. Це 256 байтів: 64 / 8 = 8 байтів на рядок, рядків 32.

адреса байта = 0xA00 + y * 8 + (x / 8)
номер біта   = 7 - (x % 8)
горить       = (mem[адреса] >> номер біта) & 1

y * 8 - крок рядка. x / 8 - який байт у рядку. x % 8 - який біт у байті. 7 - стоїть тому, що пікселі йдуть зліва направо, а біти нумеруються справа наліво. Без нього картинка вийде дзеркальною групами по вісім.

Приклад: піксель (13, 2). Байт 0xA00 + 2*8 + 1 = 0xA11, біт 7 - 5 = 2.

Якби був байт на піксель, екран займав би 2048 байтів, тобто половину пам'яті.

3. show, plot, clear на C++
bool plot(Memory& mem, int x, int y) {
    if (x < 0 || x >= 64 || y < 0 || y >= 32) return false;
    mem.data[VRAM_LO + y * 8 + (x / 8)] |= (Byte)(1u << (7 - (x % 8)));
    return true;
}

void clear(Memory& mem) {
    for (std::size_t i = 0; i < VRAM_SIZE; ++i) mem.data[VRAM_LO + i] = 0;
}

show читає біт за тією самою формулою і друкує # або крапку.

7. OUTS зі стелею
ember> load 0x800 0x48 0x45 0x4C 0x4C 0x4F 0
ember> load 0 0x04 0x00 0x08 0x00
ember> reset
ember> run
HELLO

0x04 це OUTS, 00 08 це адреса 0x0800 (молодший байт першим), 00 це HALT. Цикл у OUTS іде до нуля, але не більше 256 байтів. Якщо в програмі забули 0, без стелі він би друкував пам'ять далі й далі.
